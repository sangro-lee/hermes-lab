# Skills 운영 규칙

스킬은 반복 작업을 일정한 절차로 수행하기 위한 문서/워크플로입니다. 스킬 파일을 만들었다고 자동으로 안전하거나 검증된 것은 아닙니다.

## 라이프사이클
1. `draft/` 단계에서 초안을 작성
2. 작은 테스트 프로젝트에서 실행
3. 입력·출력·실패 상황을 확인
4. 서로 다른 조건에서 여러 번 재실행
5. 연구자가 검토
6. 승인된 경우에만 공용 스킬로 승격
7. 버전과 변경 이력을 Git으로 관리

새 스킬이 파일 삭제, GPU 제출, 외부 업로드, 권한 변경을 수행하도록 하지 말고, 필요한 동작은 명시적인 승인 인터페이스를 거치게 합니다.

이 템플릿은 라이프사이클을 문서화할 뿐, 자동 검증/승격 기능을 구현하지 않습니다.
