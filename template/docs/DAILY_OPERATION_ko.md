# 일상 운영 예시

## 매일 시작할 때
1. `research/RESEARCH_STATE.md` 확인
2. 최근 실험의 종료 상태와 로그 확인
3. `research/OPEN_QUESTIONS.md`에서 중요한 질문 선택
4. 에이전트에게 문헌/코드 조사와 실험 제안서 초안 요청
5. 실험 명세와 성공 기준 검토
6. 승인된 실험만 실행
7. 결과·코드 버전·로그 경로 기록
8. 연구 상태 업데이트 제안을 검토

## 한 번의 실험 사이클
```text
질문 정의
  → 가설과 예측 정의
  → baseline 및 metric 지정
  → 실험 명세 작성
  → 명세 검증
  → 연구자 승인
  → Slurm 실행
  → 로그/종료 코드 확인
  → 결과 분석
  → 해석 및 한계 기록
  → 다음 질문 갱신
```

## 에이전트 작업 요청에 포함할 것
- **목표:** 무엇을 알아내거나 바꿀 것인가?
- **입력:** 어떤 파일/데이터를 사용할 것인가?
- **범위:** 수정 가능한 파일과 금지 파일은?
- **제약:** GPU 시간, 패키지, 메모리, 네트워크 제약은?
- **검증:** 어떤 테스트/metric이 통과해야 하는가?
- **산출물:** 어떤 파일과 요약을 제출해야 하는가?
- **승인:** 실행/삭제/병합 중 무엇에 확인이 필요한가?
