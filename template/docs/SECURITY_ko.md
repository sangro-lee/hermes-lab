# 보안과 권한 정책

## 기본 원칙
1. **최소 권한:** 에이전트 전용 계정에는 연구에 필요한 경로와 명령만 허용합니다.
2. **비밀정보 분리:** API 키·SSH 개인키·비밀번호를 Git 저장소, 프롬프트, 로그에 넣지 않습니다.
3. **실행 분리:** 처음에는 코드 수정과 GPU 실행을 분리하고, 실행 전 diff와 명세를 검토합니다.
4. **경로 제한:** 다른 사용자의 파일이나 임의의 시스템 경로를 수정하지 못하도록 합니다.
5. **승인 기록:** GPU 제출, 취소, 삭제, 배포, 권한 변경의 승인자를 기록합니다.
6. **로그 보존:** 명령, 설정, 종료 코드, 출력 위치를 기록하되 비밀정보는 마스킹합니다.

## 처음에는 자동화하지 말아야 할 것
- `sudo` 또는 시스템 패키지/SSH 설정 변경
- 임의의 `scancel` 및 파일 삭제
- 대규모 GPU 작업의 무승인 제출
- 메인 브랜치 자동 병합
- 연구 결과를 검토 없이 외부 서비스에 전송
- 새 스킬의 무검증 자동 승격
- 자격 증명 출력, 복사, 업로드
