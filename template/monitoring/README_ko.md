# 모니터링 시작점

초기에는 복잡한 대시보드보다 다음 기록부터 확실히 남기는 것이 중요합니다.

- 실험 ID와 제출 시각
- Slurm job ID
- 사용한 commit·설정·데이터 버전·seed
- 요청 자원과 실제 실행 시간
- 종료 코드 및 실패 메시지
- 결과 파일 위치
- 승인자와 승인 시각

## OpenTelemetry는 언제 필요한가?
Hermes, 도구 서버, 실행 래퍼, 분석 파이프라인 등 여러 구성 요소를 연결한 뒤 어디서 시간이 걸렸는지, 어떤 도구 호출이 실패했는지 보고 싶을 때 검토합니다. 처음부터 설치할 필요는 없습니다.

로그에 API 토큰, 비밀번호, SSH 키, 민감한 데이터가 들어가지 않도록 필터링합니다.
